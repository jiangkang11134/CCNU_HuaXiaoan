# 定位（2026-09-21 重写）：
#   本表**只保留无法成为教学内容**的硬核词条；语义判断交给 LLM 审查
#   （config.enable_content_guard_llm）。原先照搬上游模板的默认词表，
#   把「反诈骗 / 禁毒 / 反邪教 / 网络安全 / 心理危机干预 / 爆炸风险管理」

#   有 9 条被误拦，等于系统在拦自己该教的内容。
#
# 两条硬规则：
#   1. **统一小写**。匹配逻辑是 `keyword in text.lower()`，词表不转小写，
#      所以含大写字母的条目（如 ISIS、K粉）**永远不会命中**。
#   2. 本表是**裸 substring 匹配，无词边界**。中文无法靠 \b 断词，
#      因此任何可能作为其它词一部分出现的字符串都不能放进本表
#      （例：「孤儿」会命中「孤儿进程」）。
#
# 注意：本表在 ContentGuard.__init__ 里**只加载一次**，改完必须重启服务；
#      文档里"修改后实时生效无需重启"的说法是错的。
