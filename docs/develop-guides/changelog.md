# 变更日志

## 当前版本

### Bug 修复

- 修复知识导图在数据加载后立即渲染时可能找不到 SVG 容器的问题。
- 修复知识图谱构建遇到失败 Chunk 后阻塞后续待索引 Chunk 的问题。

### 业务整合

- 整合前台问答入口与后台运营管理入口。
- 后台保留数据看板、用户管理、部门管理、知识库管理和模型管理能力。
- 前台用户按角色与部门权限访问问答能力。
- 管理员可配置前台展示、问答策略和系统基础配置。

### 界面调整

- 前后台沿用 Yuxi 原有视觉风格和组件体系。
- 移除运行界面中的外部项目仓库、文档站、Star 提示和远程资源入口。
- 默认头像和模型图标改为本地生成或本地资源。

### 部署说明

- 知识库文件需要在新系统中重新上传。
- 原业务中的 FAQ 与问答对能力使用 Yuxi 知识库现有结构承载。
- 模型供应商、OCR、解析服务等功能性 API 配置保留。
