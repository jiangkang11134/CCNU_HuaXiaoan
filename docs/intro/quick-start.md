# 快速开始

本文档面向本地部署与业务验收场景。

## 前置条件

- 已安装 Docker 与 Docker Compose。
- 已准备至少一个兼容 OpenAI 接口的大模型 API。
- 已确认对象存储、向量库、图数据库等依赖服务可正常启动。

## 初始化

```bash
cd Yuxi
./scripts/init.sh
```

Windows PowerShell 环境可执行：

```powershell
.\scripts\init.ps1
```

## 启动

```bash
docker compose up --build
```

启动完成后访问本地 Web 服务，并按页面提示创建超级管理员。

## 首次配置

1. 在后台配置模型供应商和默认模型。
2. 配置文档解析、OCR、向量库与图数据库相关参数。
3. 创建部门、用户和角色权限。
4. 上传知识库文件并等待解析入库。
5. 使用前台问答入口验证回答效果。

## 常用入口

| 项目 | 默认地址 |
| --- | --- |
| Web 界面 | 本机 5173 端口 |
| API 文档 | 本机 5050 端口的文档路径 |

生产环境请通过反向代理和域名统一暴露服务。
